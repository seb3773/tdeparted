Welcome to tdeParted Setup

tdeParted is an advanced partition editor for Linux, based on GParted and natively ported to the Trinity Desktop Environment (TDE).

Key Features:

  • Partition Management: Create, delete, resize, move, copy, check, and manage partition flags.
  • Secure Erase: Securely wipe whole disk devices with built-in sanitation routines.
  • S.M.A.R.T. Health Diagnostics: View real-time disk health and temperature telemetry.
  • Disk Imaging & Cloning: Direct drive-to-drive cloning and partition image backup/restoration.
  • Operations Queue & Script Export: Export queued partition operations as standalone bash scripts.
